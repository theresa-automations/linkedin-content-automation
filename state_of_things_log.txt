────────────────────────────────────────────────────────────────────────────────
SYSTEM OVERVIEW
────────────────────────────────────────────────────────────────────────────────
A fully automated LinkedIn content pipeline that:
  1. Generates post batches from project writeup files (linkedin_generator.py)
  2. Audits and scores drafts, auto-regenerates failures (linkedin_auditor.py)
  3. Plans and renders Mermaid diagram images for posts (linkedin_image_planner.py + linkedin_image_gen.py)
  4. Posts to LinkedIn on scheduled dates with optional images (linkedin_runner.py via LINKEDIN-POSTING-WORKFLOW.md)

Content persona: Theresa Erhumwunse — Automation Engineer / AI Systems Builder
Content strategy: Rotating 7 post types over a 30-day arc, grounded in real projects
Timezone: WAT (UTC+1)
Scheduling: Windows Task Scheduler triggers Python scripts on set days/times


────────────────────────────────────────────────────────────────────────────────
KEY FILES
────────────────────────────────────────────────────────────────────────────────
SCRIPTS
  linkedin_generator.py       — Batch post generator (runs Saturdays via Claude CLI)
  linkedin_auditor.py         — Draft auditor + auto-regen (runs Sundays 6-8 PM WAT)
  linkedin_image_planner.py   — Reads approved drafts, writes image-plan.json
  linkedin_image_gen.py       — Renders images from image-plan.json using Mermaid
  linkedin_image_post.py      — Posts text + image to LinkedIn via Python (used by runner)
  linkedin_runner.py          — Daily poster orchestrator (runs Mon-Fri 9 AM WAT)

WORKFLOW DOCS (Claude reads these as prompts)
  LINKEDIN-GENERATOR-WORKFLOW.md    — Generator instructions
  LINKEDIN-AUDITOR-WORKFLOW.md      — Auditor instructions + regen decision logic
  LINKEDIN-IMAGE-GEN-WORKFLOW.md    — Image planning + generation instructions
  LINKEDIN-POSTING-WORKFLOW.md      — Daily posting instructions

DATA FILES
  drafts.md                   — All generated post drafts with statuses
  schedule.md                 — Posting calendar with dates and statuses
  audit-log.md                — Record of all published posts
  audit-report.md             — Latest auditor run report
  generation-log.md           — Record of all generator runs
  image-log.md                — Record of image generation runs
  image-plan.json             — Structured image specs for current batch
  content-strategy.md         — Persona, post types, tone, formatting rules
  content-guidelines.md       — Detailed writing guidelines

CONFIG
  linkedin_mcp_config.json    — MCP server config (LinkedIn + local-files MCPs)
                                ⚠️ Contains LinkedIn credentials in plain text (see Fix 3 below)

FOLDERS
  Project Completed\          — Source .md project writeups for content generation
  images\                     — Generated post images (post-[N].png)
  run-logs\                   — Timestamped logs from every script run
  Archive\                    — Old/unused files

  - Privacy benefit: diagram code no longer sent to external Kroki server
  - Prerequisite: mmdc v11.12.0 installed globally (npm install -g @mermaid-js/mermaid-cli)
  - Performance: ~2-3s per image (Puppeteer startup) — acceptable for batch runs
